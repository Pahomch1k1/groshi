# Groshi

Личное iOS-приложение для учёта финансов: интерфейс в духе Spendee 6 и AI-ассистент на OpenAI.

## Структура
- `Core/` — Swift-пакет `GroshiCore` с платформонезависимой логикой. Тесты гоняются на Linux (`.github/workflows/core-tests.yml`).
  - Деньги хранятся в целых копейках (`Int64`) и пересчитываются точно.
  - Модели данных и мутации (`Mutation`): через них проходит любое изменение, что даёт отмену и атомарность.
  - Аналитика по периодам и категориям.
  - CSV-экспорт и импорт, включая формат экспорта Spendee.
  - Хранилище `FileStore`: атомарная запись JSON и ежедневные снимки.
  - AI-движок: описания инструментов OpenAI, их исполнение, подтверждения, защита от дублей.
- `App/Sources/` — приложение на SwiftUI, iOS 17+.
- `UITests/` — XCUITest-сценарии, сохраняют скриншоты.
- `project.yml` — проект Xcode, генерируется командой `xcodegen generate`.
- `.github/workflows/ios-build.yml` — сборка неподписанного `Groshi.ipa` и UI-тесты на macOS-раннере.

Установка на iPhone описана в [docs/INSTALL.md](docs/INSTALL.md).
