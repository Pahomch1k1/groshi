## 1. Назначение

Личное iPhone-приложение учёта финансов (владелец — один человек), максимально близкое к **Spendee 6**,
с AI-ассистентом на OpenAI: голосом/текстом записывать операции (одну или десятки за раз), исправлять, отменять,
управлять категориями и их порядком. Цель — не вводить операции вручную.

Имя на iPhone: **WorkFlow Spend** (раньше Groshi). Репозиторий, Bundle ID и папка данных остаются «Groshi» — так нужно.

Важно: в ТЗ владелец иногда пишет «WorkFlow Spent», «Telegram Mini App», «staging». Это ЭТО приложение
(подтверждено 2026-11-21), не WorkFlow Finance. Staging здесь нет: «на staging» = ветка + сборка IPA в
`Downloads\Groshi`, установка через Sideloadly; production-сервера с данными нет (данные только на телефоне).

## 4. Согласованные решения и требования (не переспрашивать)

- Bundle ID `app.groshi.ios` и папку данных не менять; обновления ставятся поверх без потери данных.
- Финансовую историю владельца (`Pictures\transactions_export_2026-11-19_mono.csv`) **никогда** не коммитить,
  не отправлять в CI/логи/IPA. Не создавать тестовые операции в данных владельца. Не придумывать отсутствующие данные.
- Ключ OpenAI — не в коде, не в IPA, не в публичном репо, не в логах. Платные сервисы — только с согласия.
- Категории владельца не переименовывать (даже с опечатками: «Travle», «Yumashev»…).
- Ответы владельцу — только на русском. Не смешивать с проектом WorkFlow / WorkFlow Finance.
- 0.3: интерфейс ~65–70% (плотность Spendee); баг «дёргания» вкладок не возвращать.
- 0.4: две кнопки (+ и AI), никакого озвучивания, сохранение без подтверждения + «Исправить»/«Отменить»,
  подтверждение только для вероятного дубля и массовых изменений, перетаскивание категорий, порядок голосом.
- **0.5 (ТЗ 2026-11-21 «голосовой ввод транзакций», приоритет максимальный):**
  - голосовой текст копится в **черновике** (на диске, файл `voice-draft.json` рядом с данными): новая диктовка
    дописывается; переключение приложений / сворачивание / звонок / закрытие панели / перезапуск — текст сохраняется;
    отправка только кнопкой «Отправить»; очистка — только после успешного сохранения или корзиной (подтверждение в панели);
  - «Добавлено N транзакций на сумму …» — только после реальной записи; если модель говорит «добавлено» без записи —
    одна попытка исправиться, затем ошибка, черновик остаётся;
  - частичное сохранение: полные операции пишутся, по остальным «Не добавлено: N» + вопрос AI только про них;
  - у каждого черновика свой `requestID` (ставится на операции, `Txn.requestID`) — повторная отправка не создаёт дублей;
  - ошибка сети/сервера: «ничего не сохранено», черновик остаётся, «Повторить» шлёт тот же requestID;
  - модель никогда сама не решает «уже сохранено» — повторы определяет приложение;
  - iOS: фоновой записи микрофона нет (не обещать); после возврата микрофон нажать ещё раз, текст не теряется.

## 6. Найденные и исправленные причины ошибок 0.4 / разработки 0.5

1. **AI сохранял операции не в главном потоке** (`AssistantEngine.send` был nonisolated async → инструменты и
   `store.apply` в фоне) → SwiftUI показывал записи с опозданием («появились через несколько минут») или не обновлял
   панель. Исправлено: `send(..., isolation: #isolation)`; в debug `Store.apply` проверяет главный поток; Core-тест.
2. Ответ модели показывался без проверки записи; одна неполная операция отменяла всю команду; вероятный дубль
   откладывал ВСЮ команду до кнопки; ошибка записи файла не доходила до AI. Всё исправлено (см. §4).
3. Текст диктовки жил только в памяти и сбрасывался новой записью → черновик на диске.
4. UI: системный диалог подтверждения и анимированные вставки/удаления панели/кнопок иногда оставляли окно с
   устаревшей картинкой (кнопка AI невидима, «Обрабатываю…» после сохранения). Исправлено: подтверждение внутри панели,
   видимость без анимации, `.id(phase)`, отправка без промежуточной фазы «черновик», точка записи на TimelineView.
5. **Перетаскивание категорий качалось** туда-обратно над соседней ячейкой (цель искалась по движущимся ячейкам) →
   цели — фиксированные слоты, снятые в начале перетаскивания. Подтверждено трассировкой (одна попытка, 0→1→2).

## 8. Известные ограничения / риски

- На реальном iPhone 0.5 ещё не проверялось владельцем: распознавание речи uk/ru, возврат из Monobank,

  последнее слово может не распознаться.

  ложного «добавлено» при этом нет.
- `OPENAI_API_KEY` в GitHub Secrets не задан — живые тесты только локально.
