## 1. Назначение

Личное iPhone-приложение учёта финансов (владелец — один человек), максимально близкое к **Spendee 6**,
с AI-ассистентом на OpenAI: голосом/текстом записывать операции (одну или десятки за раз), исправлять, отменять,
управлять категориями и их порядком. Цель — не вводить операции вручную.

Имя на iPhone: **WorkFlow Spend** (раньше Groshi). Репозиторий, Bundle ID и папка данных остаются «Groshi» — так нужно.

## 3. Архитектура и технические особенности

- **Без Mac.** Собирается только в GitHub Actions. Репозиторий **публичный**: github.com/Pahomch1k1/groshi
  (сделан публичным ради бесплатных минут; история переписана — email → noreply; копия до переписывания:
  `Documents/GitHub/groshi-before-history-rewrite.bundle`).
- `Core/` — Swift-пакет **GroshiCore** (модели, деньги в `Int64` минорных единицах, мутации `Mutation`, аналитика,
  CSV/импорт Spendee, AI-движок `AI/AssistantEngine.swift`, инструменты/промпт `AI/AssistantTools.swift`).
  Тесты на Linux: workflow `core-tests.yml` (контейнер swift:6.0-jammy), запускается на push в `Core/**`;
  выгружает артефакт **ai-contract** (точные tools + system prompt для живых тестов).
- `App/Sources/` — SwiftUI iOS 17, XcodeGen `project.yml`. Ключевые файлы:
  `GroshiApp.swift` (RootView: три вкладки живут постоянно в ZStack, переключение opacity — фикс «дёргания»; две FAB),
  `VoiceDock.swift` (плавающая AI-панель), `AssistantView.swift` (ViewModel + чат + настройки AI),
  `AIServices.swift` (транспорт, Gateway, распознавание речи, ScriptedTransport для UI-тестов),
  `CategoryGrid.swift` (сетка категорий с перетаскиванием), `Translations.swift` (ru-ключ → uk/en; **дубли ключей = краш**).
- `UITests/` — XCUITest на симуляторе, сохраняют скриншоты (артефакт `screenshots-and-logs`).
  Флаги запуска: `-uiTestReset` (чистые данные), `-uiTestAI` (подставной AI + «запись» без микрофона).
- Сборка IPA: workflow `ios-build.yml` (ручной: `gh workflow run ios-build.yml -R Pahomch1k1/groshi -f run_tests=true`),
  неподписанный IPA → артефакт `Groshi-ipa`. Установка у владельца: **Sideloadly**, бесплатный Apple ID, автопродление.
- **Сервер AI**: Cloudflare Worker **workflow-spend-ai** (тот же аккаунт Cloudflare, что WorkFlow, но отдельный Worker),
  код в `server/` (см. `server/README.md`), URL `https://workflow-spend-ai.espero-hotel-management.workers.dev`.
  Ключ OpenAI владельца — только секрет Worker `OPENAI_API_KEY` (взят из `Documents/GitHub/workflow/.data/tts.env`).
  Телефон сам регистрирует **токен устройства** (Keychain), сервер хранит только SHA-256. Регистрация открыта лишь
  при KV-ключе `enroll`, закрывается после `MAX_DEVICES=1`. Лимиты: модели gpt-4.1 / gpt-4.1-mini, 30/мин и 600/день
  на устройство, 1500/день всего, ограничение размера. wrangler: `npx --prefix ../../workflow wrangler …` из `server/`.
  **Сейчас зарегистрирован 1 телефон владельца** (2026-11-20 10:43 UTC, из 0.3.1); регистрация закрыта.
- **Живые тесты OpenAI** (локально, ключ не печатается): `scripts/ai-live/harness.mjs` + `scenarios.mjs`.
  `OPENAI_KEY_FILE=…/workflow/.data/tts.env node harness.mjs <ai-contract.json> <out.json> gpt-4.1`
  или через сервер: `AI_BASE_URL=…/v1 AI_TOKEN=<токен устройства>`. Запись → `node to-swift.mjs out.json
  Core/Tests/GroshiCoreTests/LiveRecordings.swift` → `LiveReplayTests` проигрывает настоящие ответы через Swift-движок.
  Записи нужно переснимать при каждом изменении tools/prompt. `gh secret set` запрещён системой разрешений.

## 4. Согласованные решения и требования (не переспрашивать)

- Bundle ID `app.groshi.ios` и папку данных не менять; обновления ставятся поверх без потери данных.
- Финансовую историю владельца (`Pictures\transactions_export_2026-11-19_mono.csv`, 4 917 операций) **никогда** не
  коммитить, не отправлять в CI/логи/IPA. Импорт делается на телефоне. Не придумывать отсутствующие данные.
- Ключ OpenAI — не в коде, не в IPA, не в публичном репо, не в логах. Платные сервисы — только с согласия.
- Категории владельца не переименовывать (даже с опечатками: «Travle», «Yumashev»…).
- Ответы владельцу — только на русском. Не смешивать с проектом WorkFlow.
- 0.3: интерфейс уменьшен до ~65–70% (плотность Spendee), без scaleEffect; баг «дёргания» вкладок не возвращать.
- 0.3.1: AI работает сразу после установки через сервер; QR/ввод ключа убраны (свой ключ — необязательная опция).
- **0.4 (текущие требования):**
  - справа внизу две отдельные зелёные кнопки: «+» (ручной ввод, в будущем бесплатно) и под ней микрофон с искрами
    (AI, в будущем Pro — **пока никаких ограничений/оплаты**); долгое нажатие на «+» и микрофон в форме добавления убраны;
  - одно нажатие на AI сразу начинает запись; паузы не останавливают; «Готово» — остановка и авто-отправка;
    «Отмена» — сброс; на экране таймер, волна, распознанный текст;
  - **никакого озвучивания** ответов; микрофон после ответа сам не включается;
  - если данных хватает — сохранять сразу, без подтверждения; панель «Сохранено N транзакций · сумма», список, дата,
    кнопки «Исправить» (вручную или голосом) и «Отменить» (весь пакет); неясно → уточняющий вопрос;
    подтверждение остаётся только для вероятного дубля и массовых изменений/удалений;
  - перетаскивание категорий (зажать → тянуть → остальные сдвигаются), в сетке добавления и в «Категориях»,
    порядок общий и переживает перезапуск; расходы и доходы упорядочены отдельно;
  - порядок категорий голосом: «на первое место», «вторая строка третье место» (=7, сетка 4 столбца), «после X»,
    «поменяй местами», «создай и поставь в начало»; изменения сразу, с отменой.

## 8. Известные баги / риски

- **testCategoryDragReorderPersists нестабилен**: в сборке 44726523592 прошёл, в 44730614449 (код перетаскивания тот же)
  упал: «Продукты» не сдвинулись (`123.67 ≯ 217.67`). Вероятно XCUITest `press(forDuration:thenDragTo:)` иногда не
  запускает LongPress→Drag внутри ScrollView (или ScrollView перехватывает жест). Возможный риск и на устройстве —
  проверить пальцем; варианты: увеличить `minimumDuration`/повторить в тесте, `highPriorityGesture`, отключать скролл во время перетаскивания.
- Если жест перетаскивания отменится системой, `finishDrag()` вызывается через `@GestureState holding` — проверить на устройстве.
- Распознавание речи: Apple ограничивает серверный сеанс ~1 мин — сделана склейка сегментов; на устройстве не проверено.
- Пицца иногда попадает в Food, а не Restaurant (решение модели, исправляется голосом).
- `OPENAI_API_KEY` в GitHub Secrets не задан (запрет системы разрешений) — живые тесты только локально.
