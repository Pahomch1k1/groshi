# Установка Groshi на iPhone (с Windows, без Mac)

Приложение собирается на серверах GitHub (macOS) в неподписанный файл `Groshi.ipa`. На телефон его ставит программа **Sideloadly** с Windows: она подписывает файл вашим Apple ID.

## Что понадобится
- iPhone с iOS 17 или новее и USB-кабель.
- Компьютер с Windows (этот).
- Apple ID. Подойдёт обычный бесплатный, платная подписка не нужна.

## Шаг 1. Скачать IPA
1. Откройте https://github.com/Pahomch1k1/groshi/actions/workflows/ios-build.yml
2. Выберите последнюю успешную сборку (зелёная галочка).
3. Внизу, в разделе **Artifacts**, скачайте `Groshi-ipa` и распакуйте zip. Внутри лежит `Groshi.ipa`.

Новую сборку можно запустить кнопкой **Run workflow** на той же странице. Сборка идёт примерно 10–15 минут.

## Шаг 2. Подготовить Windows
1. Установите **Apple Devices** из Microsoft Store или iTunes с сайта apple.com. Они нужны, чтобы Windows видел iPhone.
2. Скачайте и установите **Sideloadly**: https://sideloadly.io (бесплатно, для Windows).

## Шаг 3. Подготовить iPhone
1. Подключите iPhone кабелем, разблокируйте его и нажмите **«Доверять этому компьютеру»**.
2. Включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл**, затем перезагрузите телефон и подтвердите. Если такого пункта нет, он появится после первой попытки установки (шаг 4).

## Шаг 4. Установить
1. Запустите Sideloadly. Ваш iPhone должен появиться в списке устройств.
2. Перетащите `Groshi.ipa` в окно программы.
3. В поле **Apple account** введите свой Apple ID.
4. Нажмите **Start** и введите пароль Apple ID. Если включена двухфакторная защита, введите код с телефона.
   - Пароль уходит только в Apple. Для спокойствия можно завести отдельный Apple ID.
5. На iPhone откройте **Настройки → Основные → VPN и управление устройством**, выберите свой Apple ID и нажмите **«Доверять»**.
6. Откройте Groshi.

## Важно: продление каждые 7 дней
С бесплатным Apple ID подпись действует **7 дней**. После этого приложение перестанет открываться, но **данные не пропадут**.
- Чтобы продлить, повторите шаг 4 с тем же файлом. Это обновление поверх, данные сохраняются.
- Удобнее включить автопродление: в Sideloadly отметьте **Advanced options → Automatic Refresh**. Тогда Sideloadly сам переподпишет приложение по Wi-Fi, пока компьютер включён и находится в той же сети.
- Не удаляйте приложение с телефона: вместе с ним удалятся данные. Перед любыми экспериментами делайте **Ещё → Резервная копия**.

## Шаг 5. Подключить AI
1. Создайте ключ на https://platform.openai.com/api-keys и пополните баланс, минимум $5.
2. В приложении откройте **Ещё → AI-ассистент → Ключ OpenAI API**, вставьте ключ и нажмите **Сохранить**, затем **Проверить подключение**.
3. Голосовой ввод: удерживайте зелёный «+» или нажмите микрофон во вкладке «Ассистент». При первом запуске iOS спросит разрешение на микрофон и распознавание речи.

## Перенос истории из Spendee
1. В Spendee: **More → Export → все кошельки → весь период → CSV**. Бесплатный тариф Spendee отдаёт только последние 365 дней.
2. Сохраните файл в «Файлы».
3. В Groshi: **Ещё → Экспорт и импорт CSV → Импорт из CSV**, выберите файл, проверьте сводку и нажмите **Импортировать**.
   - Недостающие кошельки и категории создадутся автоматически.
   - Повторный импорт того же файла не создаёт дублей.

## Когда захочется больше удобства (платно, по согласованию)
**Apple Developer Program** стоит $99 в год. С ним подпись действует год вместо 7 дней, появляется TestFlight (установка «по воздуху», без кабеля), а в перспективе — публикация в App Store. Сборку для TestFlight можно настроить в том же GitHub Actions, без Mac.
